# 情绪纸星音乐瓶 UI 与动效改造设计

## 目标

以用户提供的《梦幻旋转木马音乐播放器设计稿.png》为最高优先级视觉依据，将现有静态 HTML 播放器与各弹层统一为手绘绘本风格，并完成桌面与手机响应式布局及播放状态动效。保留项目已有音乐、歌词、星星、音乐瓶和本地存储行为，不重做产品功能。

## 当前实现

- 项目使用原生 HTML、CSS 和 JavaScript，没有前端框架。
- `index.html` 包含播放器、歌词、歌曲选择、情绪与留言弹层、音乐瓶、全部星星、详情等 DOM；多轮样式覆盖也集中在该文件。
- `script.js` 管理播放、歌曲、歌词、投星、照片、星星持久化、音乐瓶和排序。音频 `play`、`pause`、`ended` 事件已统一调用 `setPlaying`，并切换 `#stage` 与 `body` 上的 `is-playing` 状态。
- 歌曲库当前只保留两首；歌曲选择弹层的说明文案仍写着“三首本地歌曲”，实施时改为与实际曲目数一致，不动歌曲数据。
- 音乐、封面、歌词、绘本插画均为项目本地资源。
- 当前分支为 `main`，`origin` 指向既有 GitHub 仓库。开始时工作区已有 `index.html`、`tests/project-smoke.test.js` 的未提交修改，以及 `assets/reference/carousel-scene.png` 新素材；这些改动与本设计范围相符，实施时保留并统一整理。

## 选定方案

采用 B：保留业务脚本、数据结构和已有交互 ID；仅对必要的展示结构做小幅调整，将视觉规则整理到独立 `style.css`。复用现有纸张、旋转木马、音乐瓶和封面素材；对需要独立运动的装饰使用轻量 CSS/SVG 层。播放器和弹层继续由原有脚本事件控制，不引入框架或动画依赖。

## 视觉与页面结构

### 全局视觉

- 使用连贯的浅米白纸张底色、低饱和水彩色、细铅笔线条、淡纸纹与克制阴影。
- 保留现有中英歌曲名称、用户照片、留言和歌曲信息，不添加虚构内容。
- 页面、歌词、歌曲选择、情绪选择、留言、音乐瓶、全部星星和星星详情使用同一套纸张面板与绘本边线语言；清理叠加样式造成的冲突。
- 保留现有字体选择与本地插画，不把整张设计稿直接铺作网页背景。

### 桌面布局

- 标题与副标题居中，投放星星作为右上角手绘纸签。
- 旋转木马和 CD 位于页面视觉中心，歌曲名与歌手置于插画铭牌区域。
- 播放控制、歌词入口、时间进度及音量置于主体下方，保持可读和易点。
- 音乐瓶入口位于右下区域，沿用本地瓶子插画并显示当前歌曲星星数量。
- 在 1280、1440、1920 像素宽度下居中流动布局，不固定整页像素尺寸。

### 手机布局

- 在 600 像素及以下采用单列阅读顺序：标题和投放按钮、旋转木马、歌曲信息、播放器控制、进度与音量、音乐瓶入口。
- 通过 CSS 断点调整实际网格和尺寸，不整体缩放桌面页面；覆盖 360、390、430 像素宽度。
- 页面和弹层禁止横向溢出；弹层适配动态视口高度、安全区和内部滚动；交互目标保持足够触控尺寸。

### CD 与播放动画

- CD 与封面容器保持 `aspect-ratio: 1 / 1`、`border-radius: 50%`，唱片孔置于中心；封面按圆形裁切，不受父级网格拉伸。
- 仅在现有真实播放状态 `.is-playing` 下启动 CD 慢速旋转、木马轻微起伏以及两匹马错时的小幅运动；暂停或结束时停止，继续播放恢复。
- 优先使用 `transform` 和 `opacity`，动画幅度克制，并支持 `prefers-reduced-motion`。
- 不增加第二个独立播放布尔状态；如果 DOM 需要更换，仅保留现有 audio 与 `setPlaying` 负责的行为。

## 功能保护边界

- `script.js`、`lyrics-core.js` 的音乐加载、播放、暂停、进度、音量、歌曲切换、歌词解析与同步逻辑保持不变。
- 保留全部脚本查询的 DOM ID、`data-*` 钩子、音频元素、文件输入和弹层关闭钩子；必要的 HTML 调整不得更改这些接口。
- 保留现有歌曲与星星关联、混合情绪颜色、照片 Base64、localStorage 键和数据字段、当前歌曲瓶、全部星星及三种排序逻辑。
- 不改变本地音乐、封面与歌词，不引入在线图片或网络音频。

## 文件范围

- 修改 `index.html`：整理展示结构和资源引用，保持现有交互 ID。
- 新增 `style.css`：集中定义纸张视觉、页面布局、弹层、CD 与响应式动效，替代冲突的内联覆盖。
- 按需新增轻量本地 SVG/图像切片；仅从现有插画中派生，不下载或编造封面。
- 修改/扩展 `tests/project-smoke.test.js`：增加样式与响应式约束检查；现有歌词核心测试保持原样。
- 不修改业务脚本，除非浏览器验证发现必须有一个最小的纯 UI 状态钩子；若发生，单独解释并覆盖测试。

## 验收与发布

- 浏览器检查 360×、390×、430× 手机宽度及 1280×、1440×、1920× 桌面宽度：无横向滚动、无越界、CD 完整圆形、旋转木马和按钮可见可用、弹层在视口内。
- 实际验证播放/暂停/继续与 CD 和木马动效同步；切歌更新封面；并回归投放多情绪星星、留言、照片、刷新持久化、当前歌曲瓶、详情及三种排序。
- 运行现有 Node 测试和新增的 UI 回归检查；只报告实际通过的项目。
- 检查 Git diff、远端、分支及待提交文件，排除临时文件、密钥和无关素材；仅提交本次 UI 改造相关改动，推送到现有 `origin/main`，不创建仓库或改写历史。

## 风险与处理

- 当前首页旋转木马主要以合成插画呈现，马并非独立图层；独立马匹动效需在不重复显示马图的前提下使用本地插画切片或克制的手绘矢量装饰。最终实现以视觉自然和保留原画为先。
- 照片以 Base64 保存在 localStorage；本次不更改其容量/存储策略，只做回归验证。
- 页面使用的字体存在远程字体导入；本次优先保留现有字体声明和系统回退，避免无关品牌视觉变化。
